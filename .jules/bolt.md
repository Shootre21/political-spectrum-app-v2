## 2025-02-20 - High Performance Substring Matching
**Learning:** In Node.js/Bun, repeatedly creating `RegExp` objects inside loops (e.g., `new RegExp(..., 'gi')`) for simple substring matching is a significant performance bottleneck, particularly inside tight loops evaluating arrays of strings like lexicons.
**Action:** When performing case-insensitive matching of static lexicons against text, cache the lowercased lexicon arrays at module load time. Inside the loop, use `text.toLowerCase()` once, and iterate using a custom `String.prototype.indexOf()` `while` loop (checking for empty strings `if (term.length === 0) continue;` to avoid infinite loops). This pattern bypasses RegExp compilation and regex engine overhead entirely, more than doubling execution speed for text analysis workloads.
