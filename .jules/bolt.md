## 2024-06-27 - Lexicon Processing Optimization via Module-Scoped Pre-computation
**Learning:** In text-analysis heavy modules like `src/lib/lexicons.ts`, continuously allocating `new RegExp(..., 'gi')` inside loops (e.g., `calculateFramingScore`, `calculateEmotionalScore`) causes massive performance overhead. Furthermore, repeatedly applying `.toLowerCase()` inside tight text-matching loops is highly inefficient. However, readability shouldn't be completely sacrificed.
**Action:** When optimizing such functions, pre-lowercase the lexicon arrays at the module scope (e.g., `OPTIMIZED_TOPICS`, `OPTIMIZED_EMOTION`) so they are computed exactly once. Replace the dynamic `new RegExp` instances with a combination of `text.toLowerCase()` executed *once* per function call, and `indexOf` while-loops to count occurrences safely and rapidly. This preserves functionality and dramatically improves performance (e.g., 2-3x speedups in benchmarks) while maintaining reasonable readability.
