## 2024-10-24 - Lexicon Analysis Optimization
**Learning:** In highly intensive string parsing workloads in V8, inline regex compilation (e.g., \`new RegExp(var, 'gi')\`) inside hot loops carries massive performance penalties. Pre-computing static dictionaries to lowercase and substituting RegExp `.match()` with `.indexOf()` in a `while` loop avoids object allocation and regex compilation entirely, resulting in ~8x speedup. Furthermore, using `for` loops with early `break` over `.filter()` arrays eliminates unnecessary allocations when performing boolean "exists" logic across large data sets.
**Action:** Always pre-process statically defined lexicons/dictionaries (e.g. `.toLowerCase()`) at the module scope when they will be frequently referenced. Avoid dynamic regex generation in hot code paths, utilizing simple string searching algorithms where exact substring matching suffices.
