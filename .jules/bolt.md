## 2024-05-18 - Optimized Text Analysis Iterations (src/lib/lexicons.ts)
**Learning:** In the text analysis engine (`src/lib/lexicons.ts`), pre-compiled RegExp objects evaluated with `RegExp.prototype.test()` must not use the global (`g`) flag to avoid maintaining `lastIndex` state across executions. However, using `String.prototype.match()` with the `g` flag safely avoids `lastIndex` state carryover while evaluating pre-compiled regex objects and is ideal for counting overlapping matches. Also, when optimizing loops by checking against lowercased module-level arrays instead of filtering dictionaries, original casing can be preserved in results by utilizing array indexes.
**Action:** When migrating frequent string comparisons to use module-level compiled Regexes, use `String.prototype.match()` to safely count matches globally. Pre-lowercase arrays at the module scope for fast iteration with `.includes()`, but ensure original casing behaviors are retained by accessing original lexicon elements via index.
