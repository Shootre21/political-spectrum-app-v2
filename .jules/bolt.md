## 2024-05-20 - Optimizing Array `.filter()` in Hot Loops
**Learning:** In string-matching utility functions like `detectTopic` (in `src/lib/lexicons.ts`), spreading static arrays and iterating over all terms using `.filter()` is extremely slow because it forces evaluation of every term, even if a match has already been found. Furthermore, converting terms to lowercase dynamically on every iteration inside a hot loop scales poorly.
**Action:** When evaluating strings against static dictionary terms to find *any* match, avoid `.filter()`. Instead, pre-compute flat lowercased arrays of terms at the module level. Use standard `for` loops inside the hot path with an early `break` or `return` when a match is found using `.includes()` or `.indexOf()`. This prevents redundant evaluations and allocations.
