## 2024-05-18 - Replacing Regex with indexOf in Hot Loops
**Learning:** In V8 (Node/Bun), while regex compilation is generally cached natively, calling `new RegExp(..., 'gi')` dynamically inside text-analysis hot loops is significantly slower (~3-4x) than using a manual `indexOf` based string counting approach when analyzing large bodies of text. This app's bias analysis engine executes deeply nested loops over hundreds of lexicon terms per article.
**Action:** For string occurrences counting in hot loops, use `indexOf` inside a `while` loop (with pre-lowercased target arrays) instead of regex matching. Additionally, when flattening objects like `TOPIC_LEXICONS` for iteration, do it once at module scope to avoid repeating object array allocations inside `detectTopic` on every article analysis.
