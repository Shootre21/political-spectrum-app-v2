## 2024-04-15 - Optimize Text Analysis Engine
**Learning:** In the text analysis engine (`src/lib/lexicons.ts`), pre-compiling RegExp arrays at the module scope prevents recreation during each function call. Using `String.prototype.match()` with the global (`g`) flag safely avoids `lastIndex` carryover issues compared to `RegExp.test()`, making it ideal for counting overlapping matches. Furthermore, replacing `Array.filter()` with early-exit loops (e.g., `for` with `break` or `return`) improves performance by avoiding unnecessary iterations once a match is found.
**Action:** Next time working on text parsing or sentiment engines in this codebase, pre-compile regexes at the module level and prefer early-exit loops over array iteration methods like `.filter()` to minimize overhead in hot loops.
