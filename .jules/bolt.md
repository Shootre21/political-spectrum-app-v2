## 2023-11-20 - [Performance] Replacing N+1 queries with single batched OR query
**Learning:** In the `compareSources` feature of `src/lib/analytics.ts`, querying the database individually for multiple sources inside a `Promise.all` created an N+1 query bottleneck. Direct SQLite benchmarking indicates that fetching all required data in a single batched query using an `OR` array, followed by filtering the grouped logic in-memory using `.includes()`, yields around a 60x performance improvement over looping queries.
**Action:** When mapping over items and executing `db.findMany({ where: { field: { contains: value } } })`, prefer to construct a single `findMany` query with an `OR` operator and perform the substring/contains matching in memory to recreate the original logic. Always include a guard clause checking for empty arrays to prevent unconstrained full-table scans.
