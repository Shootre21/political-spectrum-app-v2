## 2025-02-23 - Fast String Matching Replaces Regex Instantiation
**Learning:** In hot path text processing, dynamically allocating regular expressions `new RegExp(...)` within a loop (as done in the framing and emotional score functions) introduces significant garbage collection overhead and regex compilation time. However, string searches (`indexOf`) are natively optimized in V8/JavaScriptCore.
**Action:** When determining the frequency of exact substrings (like lexicon terms) across text payloads without complex pattern requirements, use an `indexOf` while-loop to iterate and count occurrences. This avoids inline compilation and GC pressure, providing significant performance speedups. Always advance the position pointer by `term.length` to mimic the non-overlapping behavior of regex matches.
