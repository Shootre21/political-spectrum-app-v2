## 2025-02-23 - Safe RegExp Reusability with Global Flags
**Learning:** Extracting `RegExp` objects with the global (`g`) flag to module scope to avoid re-creation overhead usually introduces bugs due to `lastIndex` state carryover when evaluated with `RegExp.prototype.test()` or `RegExp.prototype.exec()`. However, the `String.prototype.match()` function automatically resets the internal `lastIndex` property of the `RegExp` object before executing, making it safe for global scope reusability in scoring algorithms that need to count overlapping matches.
**Action:** When creating high-performance text scanners in Node/Bun using module-scoped regex objects with the `g` flag, exclusively use `String.prototype.match()` to maintain safety and deterministic behavior without manually managing `lastIndex` resets.
