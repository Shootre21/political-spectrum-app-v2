## 2025-05-09 - RegExp and case matching optimizations in text processing loops
**Learning:** When refactoring hot-path string detection loops, removing `toLowerCase()` during the text-check to improve performance can introduce functional regressions if the dictionaries are assumed to be strictly lowercase but have the potential for uppercase terms. Pre-compiling dictionaries at the module scope is safe, but must strictly pre-lowercase strings. Additionally, iterating over a pre-lowercased array while needing to return the original cased string requires an index-based loop `for (let i = 0; i < ...; i++)` to map the found match back to the original source array.
**Action:** When migrating from `text.toLowerCase().includes(term.toLowerCase())` to `text.toLowerCase().includes(term)` for performance, ensure the pre-cached `term` array is definitively lowecased during initialization, and use index-mapping if the return value requires the original casing.
